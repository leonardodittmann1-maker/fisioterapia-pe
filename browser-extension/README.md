# SwipeClean para Google Fotos

1. Extraia o ZIP em uma pasta.
2. No Chrome para computador, abra `chrome://extensions`, ative **Modo do desenvolvedor** e clique em **Carregar sem compactação**. No Edge, use `edge://extensions`.
3. Selecione a pasta que contém `manifest.json`.
4. Abra [Google Fotos](https://photos.google.com/), abra uma foto ou vídeo e clique no ícone do SwipeClean na barra de extensões.
5. Deslize na faixa do SwipeClean ou use os botões. A esquerda marca para descarte e a direita mantém. Para excluir, abra **Revisar**, volte à mídia marcada e use **Mover foto aberta para a lixeira** ou a lixeira do próprio Google Fotos.

As decisões ficam no navegador. A extensão usa os controles da página, cuja aparência e nomes podem mudar. Se ela não encontrar a seta ou a lixeira, use o controle correspondente do site. Se uma navegação recarregar a página, clique novamente no ícone para abrir o SwipeClean.
